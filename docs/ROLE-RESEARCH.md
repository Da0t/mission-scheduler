## Candidate for a later project

A C++/Linux hardware test harness would add more variety than another network dashboard. A possible purpose is to validate a low-cost environmental sensor or microcontroller before a field deployment: execute scripted test sequences, capture responses, inject timeouts, and generate repeatable pass/fail reports. Start with a documented device simulator if hardware is unavailable, and clearly distinguish simulated from physical tests.

Useful evidence: CMake builds, RAII/resource management, serial I/O when hardware exists, state-machine tests, sanitizers, and measured test behavior on Linux. This is a recommendation inferred from the posting examples and résumé coverage, not a new project that has been started.
